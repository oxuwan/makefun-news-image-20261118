A newspaper front page that sums up Wednesday 18 November 2026 in a single 1024×1024 image, drawn from scratch with Pillow (flat colours and simple shapes, no photos). The masthead names the day; the lead story is the first-ever US–China–Russia gathering assembling at APEC in Shenzhen — Xi Jinping's unprecedented tarmac greeting of Donald Trump and the Trump–Putin banquet handshake, with the trilateral itself set for Thursday 19 November. Below it, the US–Iran war widening into Kuwait and Bahrain with the day's oil prices (Brent $91.69, WTI $84.06), then the Gaza Board of Peace report, the Ethiopia–Eritrea border build-up, and Mary Peltola's Alaska win completing a 56–44 Democratic Senate majority, plus an "Also Today" strip of seven more verified stories from Ukraine to Voyager 1. Every fact comes from research verified against Reuters, AP, BBC and CNN.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This copies `entry.png` to the output directory (or `/output` by default), refusing if the image exceeds 1 MiB. The image itself is generated by `../dev/make_image.py` (not part of the entry; see the repo history for the build).
